# Testes da v1.1.2

## Testes técnicos

Execute na raiz do repositório:

```cmd
npm install
npm run typecheck
npm run lint
npm run build
```

Os três comandos devem terminar sem erros.

## Testes funcionais rápidos

1. Entrar no sistema.
2. Abrir Configurações e gerenciar uma lista personalizada.
3. Abrir Cursos e entrar nos detalhes de um curso.
4. Confirmar que o ícone do curso aparece normalmente.
5. Testar Estudos no celular em 375, 390 e 430 px.
6. Abrir e fechar o menu lateral móvel.
7. Confirmar que nenhuma migration nova é solicitada.
