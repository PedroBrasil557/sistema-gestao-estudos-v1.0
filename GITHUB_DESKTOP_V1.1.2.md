# Atualizar a branch pelo GitHub Desktop — v1.1.2

1. Mantenha selecionada a branch `correcao-v1.1.1` ou renomeie/crie `correcao-v1.1.2`.
2. Descarte as alterações ainda não commitadas da cópia incorreta, se necessário.
3. Preserve `.git` e `.env.local` na pasta do repositório.
4. Copie os arquivos desta versão para a pasta aberta por **Repository → Show in Explorer**.
5. Execute `npm run typecheck`, `npm run lint` e `npm run build`.
6. Faça o commit: `Corrige TypeScript, ESLint e build na v1.1.2`.
7. Clique em **Push origin**.
